# Prompt Collection

This directory contains the system and user prompts used in our experiments evaluating prompting strategies for energy-efficient code generation using large language models (LLMs).

## Directory Structure

- `initial_analysis/`: Prompts used in the initial Python-only analysis, covering all 22 prompting strategies including the baseline prompt.
- `final_analysis/`: Prompts used in the final analysis, covering the 8 selected prompting strategies and the baseline prompt evaluated for Python and C++. Prompts in this directory are organized by programming language.
- `prompt_usage_examples`: Example Usage for all 22 prompting strategies for [LeetCode Problem 40:Combination Sum II](./prompt_usage_examples/leetcode_40_combination_sum_II.json) 

## Prompt Format

Each prompt is provided as one or more text files, depending on the conversation type:

- **Single-turn prompts:**
    - `prompt_<ID>_system.txt`: System-level instructions supplied to the model.
    - `prompt_<ID>_user.txt`: User-level instructions supplied to the model.

- **Multi-turn prompts:**
    - `prompt_<ID>_system.txt`: System-level instructions supplied to the model.
    - `prompt_<ID>_user_turn_<N>.txt`: User message for turn `<N>`, where each turn is stored in a separate file.

The turn numbers indicate the order of the user messages in the interaction. Together, these files document the prompt structure used for each prompting strategy.
Prompt IDs are used to associate each prompt with its corresponding experimental configuration and results.
