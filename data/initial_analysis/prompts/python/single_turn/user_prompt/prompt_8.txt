You may assume that each input would have exactly one solution, and you may not use the same element twice.
Example:
Given nums = [2, 7, 11, 15], target = 9,
Because nums[0] + nums[1] = 2 + 7 = 9,

# Step 1: Initial Solution
```python
from typing import *
import random

class Solution:
    def twoSum(self, nums, target):
        hashtable = dict()
        for i, num in enumerate(nums):
            if target - num in hashtable:
                return [hashtable[target - num], i]
            hashtable[nums[i]] = i
        return []
```

# Step 2: Analysis
The above solution is a brute-force solution checks every pair, and it has O(n^2) time complexity. This is inefficient for large arrays. We can optimize it using a hash map to reduce it to O(n).

# Step 3: Optimized Code
```python
from typing import *
class Solution:
    def twoSum(self, nums, target):
        seen = {}
        for i, num in enumerate(nums):
            if target - num in seen:
                return [seen[target - num], i]
            seen[num] = i
```

# Explanation
We use a hash map (seen) to store each number's index while iterating.
This allows us to check for the complement in O(1) time, reducing overall complexity to O(n).
